# Flow Matching 学习计划

## 目标与当前位置

本阶段位于 VLA 路线的 Diffusion Policy 之后、ACT 对照之前。在 DeepLearningFoundations 中通过二维实验，建立可解释的生成机制：

> 噪声与目标样本 → 概率路径 → 速度监督 → 条件速度场 → ODE 采样 → 分布评测 → 动作生成映射

已有前置基础：二维 DDPM、Behavior Cloning、CNN 和 D2L Ch10；Diffusion Policy 已按“机制学习与有界验证”收尾。此前 FM 衔接只涉及插值、速度标签与 ODE 更新，不代表本阶段已完成。DP 的长程训练与多训练 seed 性能复现仍属暂缓扩展，不占用本阶段主线。

最终目标是能从公式、代码和几何直觉解释 Flow Matching，完成一个条件二维生成实验，并用受控采样实验分析积分步数与质量、延迟的关系。按 gate 推进，不指定完成天数。

## 最小实验定义

### 条件与目标数据

任务条件 c 是类别标签：

- c=0：水平双峰，中心 (-2,0)、(2,0)。
- c=1：垂直双峰，中心 (0,-2)、(0,2)。
- 每种条件内部两个峰等权，各方向标准差 0.3；两种条件采样等权。
- 源分布为标准二维高斯，与目标样本独立配对。
- 模型使用简单条件编码（如二维 one-hot），不依赖 attention。

每种条件都保留多模态，避免只把 c 设计为“选左峰或右峰”而掩盖多模态生成问题。c=0 与已有 DDPM 的水平双峰对齐，用于后续对照。

### 记号与方向

本阶段固定：x₀ 表示噪声起点，x₁ 表示数据终点，t 从 0 走到 1。这个端点约定与 DDPM 中 x₀ 表示干净数据不同，必须在笔记与代码中明确。

线性路径与路径速度目标：

$$
x_t=(1-t)x_0+t x_1,\qquad u_t=x_1-x_0.
$$

速度网络与训练目标：

$$
v_\theta(x_t,t,c)\in\mathbb{R}^2,\qquad
\mathcal L=\mathbb E_{c,x_0,x_1,t}\left[\|v_\theta(x_t,t,c)-(x_1-x_0)\|_2^2\right].
$$

推理时从新的噪声出发，固定任务条件 c：

$$
\frac{dx_t}{dt}=v_\theta(x_t,t,c),\qquad
x_{t+h}=x_t+h\,v_\theta(x_t,t,c).
$$

训练时 x₁ 用来构造路径与标签，不作为网络输入；推理时没有目标数据 x₁。训练也不需要先把整条 ODE 积分出来。

### 两个“条件”的区别

CFM 中的 conditional path 指用端点等辅助变量构造可直接监督的路径。这里的 c 是额外的任务条件，决定目标分布。二者不是同一个概念。

对于多个配对经过相同 (x_t,t,c) 的情况，MSE 训练的是该位置与时刻的条件平均速度。每对样本的直线路径只用于构造监督；学习后的生成轨迹不一定笔直，也不需要复现某个特定训练配对。

## F0：定位与全局地图

本轮问题：已有噪声预测框架如何换成速度回归？它在训练与生成中分别做什么？

任务与出口：

- 定向读论文动机与方法概览，画训练和推理两张图。
- 对齐 DDPM 与 FM 的端点、时间方向、监督目标、网络输入输出和采样更新。
- 能说明“CFM 的路径条件”与“任务条件 c”不同。
- 能解释为什么推理需要多个速度预测，而训练可以直接采一个随机 t。

本关不写训练代码。通过标准是用自己的话完成上述地图与解释，而不是读完摘要。

## F1：数据、路径和速度标签

本轮问题：监督标签从何而来？如何证明路径公式在实现中没有错位？

任务：

- 生成两种条件的数据并检查峰中心、方差与比例；独立生成 train/validation，记录 seed。
- 为每个 batch 样本独立采样 t∈[0,1]，取噪声 x₀、数据 x₁，构造 x_t 和 u_t。
- 打印 x₀/x₁/x_t/u_t 的 [B,2]、t 的 [B,1] 和条件编码的 [B,2]；解释广播。
- 检查 t=0/1 的端点，以及同一配对下路径速度与有限差分一致。
- 可视化若干配对路径、不同 t 的点云与速度箭头。

通过标准：端点和有限差分检查成立；能逐项解释来源、形状与物理含义；不把固定配对速度误认为全局常量速度场。不会将独立配对称为经过优化的最优传输耦合。

## F2：速度网络与训练闭环

本轮问题：模型学到单条配对速度，还是能用于新样本的速度场？

任务：

- 使用小型 MLP 接收 x_t、t 与 c，输出二维速度。
- 先固定小 batch 及其配对、时间与标签，做有限的过拟合诊断。
- 正式训练时重新采样噪声配对与 t，验证样本独立于训练数据。
- 固定 validation 配对与 t，使不同 checkpoint 的 loss 可比较；与零速度预测器及未训练同结构网络比较。
- 保存模型、配置和数据/评估 seed；记录训练曲线与有限梯度检查。

通过标准：固定监督可被学习；正式训练与验证无 NaN/Inf；验证误差优于基线。不能要求随机配对目标的完整训练 loss 接近零，也不能用固定 batch 成功声明分布生成成功。

## F3：Euler 积分与新噪声生成

本轮问题：如何将局部速度预测组织成完整生成轨迹？

任务：

- 先用解析常量速度检查 Euler 更新、方向、步长与终点。
- 实现 N 步、h=1/N 的采样：从新高斯噪声出发，按 t=j/N 查询网络并走到 t=1。
- eval 模式与无梯度执行；任务条件沿整条生成轨迹保持固定。
- 保存起点、中间点与终点，分别查看 c=0、c=1 的生成分布。
- 在新进程中加载 checkpoint，重现固定 seed 的采样。

通过标准：解析自检与实际采样均运行通过；形状始终为 [B,2]；生成与训练配对明确分离；能解释为何标签速度恒定而网络采样轨迹可弯曲。

自检中若使用已知端点构造 oracle，只能证明积分更新正确，不能作为模型生成质量证据。成熟 ODE solver 可在 F4 作为参考，不是 F3 的前置依赖。

## F4：条件有效性与步数—质量权衡

本轮问题：c 是否实际改变分布？少步积分的损失来自哪里？

实验协议：

- 首先用一个训练 seed 完成学习闭环，不强制昂贵的多训练 seed 复现。
- 默认每种条件生成 4096 个样本，用采样 seeds 0、1、2 检查结果稳定性；区分采样 seed 与训练 seed。
- 同一 checkpoint、同一初始噪声和相同条件下，比较 Euler N=10、50、100；若资源需要调整，在比较前记录选择。
- 测量采样时间与速度网络调用次数；GPU 测量先预热、计时边界同步，注明设备与 batch size。
- 保留每种条件的峰比例、峰中心误差、峰内离散程度以及偏离目标区域的情况，配合散点和生成轨迹解释。
- 对同一初始噪声切换 c，核查输出是否转向对应目标分布。

通过标准：两种条件各自生成对应的双峰；没有用均值和方差掩盖模式丢失；能用量化结果说明步数权衡。成功判断参考已有二维 DDPM 的指标尺度，并在看正式结果前确定阈值；若调整阈值必须记录原因。

本关只改变推理步数。若额外训练无条件/移除 t 的消融，需另行说明问题与预算，不默认添加。

## F5：与二维 DDPM 对照

本轮问题：两种生成方法在同一目标上有何不同，哪些差异能够由当前实验支持？

任务：

- 只将 CFM 的 c=0 水平双峰与已有无条件二维 DDPM 比较；垂直双峰是条件验证，不混入同任务排名。
- 对齐目标数据参数、样本数、评测规则、运行设备与计时方法。
- 明确两种时间记号、预测目标、采样更新及速度网络/去噪网络调用次数。
- 保存对照表：质量指标、采样成本、模型规模、历史训练预算与失败现象。
- 若 DDPM 历史日志或运行依赖不全，只做已保存产物可支持的机制/质量比较；缺失成本填“未测”，不编造数字。

通过标准：区分受控的同 checkpoint 积分步数实验，与存在训练预算/架构差异的历史 DDPM 比较。noise MSE 与 velocity MSE 的量纲和目标不同，不能直接用 loss 大小排名方法。

CFM 使用任务标签而历史 DDPM 无条件，输入与学习任务存在差异；即便在相同目标上比较，也不能据此声明算法公平胜负。真正的同预算方法比较属于可选扩展，不阻碍本阶段收尾。

## F6：向上归位、动作生成映射与收尾

本轮问题：二维生成的每个模块将如何服务 VLA 的动作生成？

需要能独立解释：

1. probability path、配对路径速度与模型学习的速度场分别是什么？
2. 为什么速度监督可直接计算，而生成需要 ODE 积分？
3. x₀/x₁、t/c 和速度目标来自哪里，生成时哪些变量不可用？
4. 同一当前位置可能对应多个配对目标，MSE 如何形成可用于采样的速度场？
5. 少步 Euler 的数值误差与速度网络本身的预测误差如何区别？
6. 将 [B,2] 换成 [B,H,D_a] 动作块后，条件 c 如何换成视觉、状态和语言表示？
7. 速度场生成与 action queue/receding-horizon 执行分别负责什么？

最终产物：公式—代码地图、路径自检、训练/验证曲线、checkpoint 索引、分条件生成图、步数实验表、DDPM 对照表和一份失败/边界记录。

收尾要求：在新进程复现采样；有理解检查和运行证据；能指出已验证与未验证的边界。二维实验不声明机器人控制、真机泛化或 FM 优于 DDPM。

通过 F6 后返回 VLA 路线，进入 ImitationPolicyLearning 的 ACT 对照阶段；具体训练规模与预算根据资源及学习目标重新确定，不自动恢复此前暂缓的 DP 长程训练。
